## 🚀 Features

- 🔐 Secure session-based user authentication (Flask-Session + bcrypt)
- 🛍️ Product previews with blur-effect backgrounds
- 🧾 Cart + Payment interface with QR support
- 🔑 Admin panel for user and product management
- ⚙️ Clean UI with modular templates
- 🌐 Git-integrated version endpoint `/version`
- 🤖 Ready for AI add-ons like OpenAI integration
